# README-обоснование

В проекте использован подход Feature-Sliced Design (FSD).

- `entities/users` — отдельная сущность, которая может понадобиться в разных частях приложения. Поэтому API для получения пользователей, store для их хранения и типы находятся в этом слое.
- `widgets/users-list` отвечает за отображение блока UI и не содержит бизнес-логику.
- `features/filter-users` — фича, потому что фильтрация является действием пользователя: он хочет отфильтровать список пользователей.

В проект добавлен `style-guide` по FSD. По возможности добавляю его в каждый проект, потому что мне очень нравится этот подход.

ИИ не использовался намеренно, юзал только для написания MD-файлов и функции debounce; архитектура и код выполнены мной.
